# Userese Video v0.1.0 · 口播剪片台

**这一段，用哪一遍？**

把反复录制的口播整理成可比较、可修改、可追溯的成片。AI 提建议，你来决定。

首个公开 alpha 版本提供：

- 本地网页审片、命令行与配套 Skill。
- 按语义段比较候选，连着前后试听，保存取舍与修改意见。
- 人工字幕纠错、冲突保护、决定快照导入导出。
- 从保存的决定生成 MP4、字幕、首帧封面与时间映射，保留历史版本。
- JSON/SRT 导入、多原片、完整短句拼接候选和可选本地转写。
- 不含真人素材、无需模型或账号的合成演示。

从 [README 快速开始](https://github.com/AsherLay/userese-video#快速开始)。需要 Python 3.10+ 和包含字幕渲染功能的 FFmpeg。安装包不包含系统 FFmpeg 或语音模型。

本版面向使用命令行或 AI 助手的创作者，采用本地个人工作流。自动语义分组、复杂视觉模板、团队权限和视频平台上传不在本版范围。源项目与完整交付包可能包含私有转写，仅按需要分享视频、字幕和封面。

测试覆盖实际视频编码、字幕与时间线、版本保留、独立项目导入、HTTP 访问控制，以及浏览器试听、编辑、生成、下载、恢复、并发冲突和四种屏幕宽度。远端结果见 [GitHub Actions](https://github.com/AsherLay/userese-video/actions/workflows/test.yml)。
